# Pandas · NumPy · EDA Workshop

Hands-on workshop covering the **foundational skills** every Data Scientist needs:

- NumPy array operations and broadcasting
- Pandas data loading, cleaning, transformation
- Exploratory Data Analysis (EDA)
- Feature engineering basics
- Visualization with Matplotlib & Seaborn
- Simple statistical summaries

## How to Run

```bash
pip install -r requirements.txt
jupyter notebook
```

## Skills Gained

- Confident data manipulation in Pandas
- Clean, reproducible EDA workflows
- Identifying missing values, outliers, distributions
- Creating useful features for downstream ML
